# Revised manuscript

The PDF is the complete reader-facing paper: main methods/results/costs, supporting appendices, and references. No author worklist or editorial letter is part of the article. Figures are editable vector TikZ/PGFPlots source.

Compile `CAENL_revised.tex` with pdfLaTeX in a CAS project, or run `python3 build.py` with a full TeX Live installation. CAS class/support files are included. Required packages include STIX, natbib, amsthm, TikZ/PGFPlots, algorithm/algorithmicx, xurl, seqsplit, microtype and multicol. Do not mix a replacement text font with STIX mathematics without checking every math symbol.

The repository's manuscript source and PDF are versioned with the accompanying research records. Highlights and editorial correspondence are separate submission files and are not appended to the article.

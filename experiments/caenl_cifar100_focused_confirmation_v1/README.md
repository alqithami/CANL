# Frozen focused CIFAR-100 confirmation source

`source/` contains the exact 20 source files and original `SOURCE_MANIFEST.json`
executed for the completed 160-treatment, 40-prefix campaign. Public wrappers,
test adaptations and this README remain outside that immutable tree. The CPU
workflow at `analysis/cifar100_focused/` verifies every original source digest.

The source retains the complete six-method development record, four selected
recipes, power assessment, prospective scope amendment, frozen analysis, vendor
losses and applicable licenses. The 54 development outcomes include SupCon and
NONL; neither method was included in the amended confirmation family.
Read `source/README_CONFIRMATION.md` for the exact training contract.

The original programs retain non-sensitive pinned deployment-root defaults and
GPU safety locks. They are historical executable sources, not a new unrestricted
cross-host launcher. A new hardware, data or filesystem deployment requires
separate input verification and fresh outputs. Do not weaken the source checks,
substitute seeds, retune from the test set, or replay existing attempts.

The released scores and provenance are at `results/caenl-cifar100-focused-v1/`.
CPU statistical reconstruction needs neither the original host nor raw images
or complete model binaries. It is distinct from independent GPU replication.
